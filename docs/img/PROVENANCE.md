# Header artwork provenance

`banner.svg` is original hand-authored SVG created for Userspace Router on November 7, 2026.
Its packet-flow icon, typography layout and geometry are original; no FerroDNS logo,
branding or assets were copied. The requested reference was the public
[tczartoryski/ferrodns repository](https://github.com/tczartoryski/ferrodns): a wide,
dark header, mint geometry, monospace title and concise subtitle informed the design.
The coordinator fetched the actual reference README and SVG through GitHub and inspected the rendered repository in Chromium. The supplied header description let the isolated coding sandbox follow that verified reference without copying its assets. The SVG uses only local shapes and text, with no fonts,
scripts, external references or embedded media. This provenance note grants no license.

The README overview image reuses the existing genuine `frames/0000.png` capture;
it is not a generated mockup. The coordinator inspected the actual overview capture, all twelve captured frames, desktop/mobile/offline images and decoded movie frames before public visibility.
